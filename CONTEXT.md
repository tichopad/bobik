# Bobik

Bobik runs an agent against a Markdown vault, either once or in watch mode.

## Language

**Watch service**:
A managed instance of Bobik in watch mode for a vault. It can perform many runs during its lifetime.

**Run audit**:
The record of an individual Bobik run, including tool calls, results, and token usage.

**Service log**:
The operational record of the watch service, including lifecycle events and run outcomes.
